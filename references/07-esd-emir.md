# 第 7 章 ESD、Latch-up 与 EM/IR

本章覆盖 ESD 路径、latch-up、PERC CD/P2P 与 EM/IR 检查。器件认证、路径检查与功能/硅后结果要分层解释。

### Q061 ESD 检查如何与版图结构对应

**要点**：先确认被保护端口、应力模式、正负极性、电源状态和预期泄放路径。核对保护器件、金属/via、回流及跨域连接，区分逻辑拓扑与布局电阻/电流密度。路径通过检查不自动证明所有器件和全部标准条件达标。

**自测**：画 signal pad 到 rail clamp 的路径，并指出薄弱处。

### Q062 PERC CD P2P 关注什么

**要点**：PERC 按 deck 做适用可靠性检查；CD关注路径电流相关的局部电流密度，P2P关注指定点间路径电阻等目标。准确输入、起终点、器件处理和限制决定结论。不能把所有 PERC PASS 简化为完整 ESD 认证。

**自测**：同一路径电阻低但局部单孔密度高，会发生什么？

### Q063 PERC CD 检查的电流条件怎样准确表述

**要点**：PERC CD 检查输入中的电流条件以安培为单位（例如 2A、5A 这类档位值）：A 是电流单位，CD 是电流密度（current density）检查类型，不能把档位数字读成“电流密度是多少安培”。准确的表述是“在相应电流条件下完成 PERC CD 检查验证”，不能升级成实测浪涌、HBM 等级或全部保护认证。具体路径与档位映射按实际 deck 配置准备。

**自测**：对方追问“这是实测吗”，用一句话准确回答。

### Q064 增加 clamp 数量为何需验证均流

**要点**：更多器件可能分担电流，但触发、路径阻抗和连接不均可让局部过载。检查每支路器件与金属/via，不能将单器件能力乘数量作为系统保证。与专家确认模型/实测依据和适用条件，再验证实际布局。

**自测**：两个 clamp 间距离不同，会影响哪些结论？

### Q065 负压 pad 的验证重点

**要点**：检查寄生结、阱/衬底偏置、器件压差、关断/漏电与保护路径。电位平移等补充验证方案需经器件/ESD 专家确认，不是所有 PERC 检查的统一限制或通用修复办法。电位平移后仍需确认模型、参考和规则覆盖等效，功能/漏电由前端配合验证。

**自测**：分别说清你、ESD专家和前端的职责。

### Q066 Latch up 与 ESD 如何区分

**要点**：ESD是瞬态应力保护问题，latch-up涉及寄生正反馈被触发并维持；某些结构和路径会同时相关，但检查/测试目标不同。guard ring、tap 和 clamp 不能简单混为一体。testchip 上的极限验证素材不代表常规产品的完整独立签核。

**自测**：解释触发与保持条件为何不同。

### Q067 EM 与 IR drop 的差别和耦合

**要点**：EM关注互连原子迁移与寿命相关风险，IR关注路径压降与性能；局部温度、几何和电流分配使二者耦合。先核对tech、温度、波形、边界，再看具体线段/孔与回流。解决EM热点也要重新看IR和寄生，反之亦然。

**自测**：发现提取/EM 使用的 tech 与实际工艺不匹配时，为什么应先纠正输入？

### Q068 平均 RMS 峰值电流如何使用

**要点**：有向平均、RMS、峰值分别反映不同统计和应力特征，按工艺DC/AC、恢复、峰值和自热规则解释。双向电流平均为零并不免检。各支路和有效通孔可能不均流，不能把总电流均摊当成最终结果。

**自测**：单向10mA、25%占空比矩形脉冲，说明平均2.5mA、RMS5mA与峰值10mA各是何种量。

### Q069 动态压降怎样改善

**要点**：确认真实电流时序、供电源/封装、回流与网格阻抗，寻找局部供电薄弱、共享路径或去耦配置问题。可以比较增加供电接入、调整层间连接/网格与去耦等方案，但需核对启动、频响及可靠性。只看DC电阻不能解释全部动态行为。

**自测**：顶层线不能再加宽时，提出可验证的替代手段。

### Q070 自热 老化与车规要求怎样谈边界

**要点**：局部温度影响互连、电路与寿命，老化需要偏置/时间模型；车规要求不能用“更宽金属”概括。介绍车规项目经验时，讲清自己承担的版图与验证工作；具体寿命、温度等级与认证状态以项目报告为准。没有主导完整资格验证、硅后失效分析或模型开发时，不借用他人案例充当个人成果。

**自测**：参与车规项目与主导车规资格认证有什么不同？车规专题进一步解释寿命档位与任务剖面。
