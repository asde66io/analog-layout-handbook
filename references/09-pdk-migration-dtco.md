# 第 9 章 PDK 迁移、封装复用与 DTCO

本章覆盖 PDK 迁移、LVL/layer map、封装复用、DTCO 与 PPA 口径。量化权衡是方法，未亲自实施的前沿技术按理解层次介绍。

### Q081 PDK 升级复用需分哪些差异

**要点**：模型/PCell/CDF、层定义与映射、几何/密度/可靠性规则、提取tech、脚本API和集成/封装接口。先做版本差异与影响清单，再决定保留、修改与回归范围。例如一次 ADC IP 复用可能既有工艺升级，也有隔离与 pad 集成变化，不能都归成 rule 修改。

**自测**：将一次 IP 复用改动按工艺、几何和接口三类归档。

### Q082 LVL 与 DRC vs DRC 的证明边界

**要点**：LVL定位图形变化，DRC结果对照帮助识别新增/消失的违例，它们不能证明完整功能、模型或电学等价。大规模dummy/fill差异须有范围过滤依据，以免掩盖真实走线变化。配合LVS、PEX、可靠性和接口检查形成结论。

**自测**：差异很少却功能坏，哪些检查能补上？

### Q083 Layer map porting 最怕哪些错误

**要点**：同编号不同语义、purpose/text/marker遗漏、数据单位、层间连接和器件识别差异。按语义建立映射并用已知结构核对；一键转换不等于工艺移植完成。介绍相关经历时按实际承担的工作（如映射整理维护与 PV 回归）说明，不把协助工作升级为开发整个 PDK。

**自测**：映射后金属图形相似，但LVS全错，先查什么？

### Q084 新 pad 与隔离层如何影响复用

**要点**：新位置改变连接、回流、天线、寄生和ESD路径，新增隔离可能改变边界与tap规则。例如某 ADC IP 复用时新增若干信号 pad，属于接口重布，而不是原来缺失全部 ESD。核对预期范围与新的顶层环境。

**自测**：新增隔离层为何不能只跑一遍DRC？

### Q085 FC 转 Wirebond 的回归清单

**要点**：确认pad/端口映射、顶层线道、PG/ESD回流、负载/封装模型、隔离/应力与最终签核设置。底层复用也需评估环境变化。按实际影响确定后仿、EM/PERC和接口复核，避免把新封装当成仅换一个开关。

**自测**：说明封装变更前与前端、封装团队的预先沟通如何减少后期返工。

### Q086 DTCO 与一般面积优化有何关系

**要点**：DTCO将工艺选项与设计实现协同评估，通过结构、规则和测试/模型比较系统收益。一般版图优化可以提供痛点与数据，但不意味着版图工程师主导了工艺开发。明确评估载具、输入版本、指标与成本/可靠性边界，别只说“面积更小”。

**自测**：给工艺团队一条规则反馈时应附什么证据？

### Q087 PPA 对模拟电路应怎样定义

**要点**：性能可能是失调、噪声、带宽、建立时间或线性度，功耗需绑定偏置/活动和PVT，面积需说明器件、block和顶层口径。先列硬要求，再比較候选方案的有效收益与代价。单一寄生数值或bbox压缩不代表整体更优。

**自测**：同一电容阵列两个走线方案怎样做公平比较？

### Q088 BPR BSPDN GAA 等怎样回答经验边界

**要点**：理解结构和潜在布线/供电影响，分清埋入轨、背面网络和器件架构，并认识工艺实现有多种方式。明确自己的实际经验覆盖哪些工艺；对未亲自实施的技术（如 GAA、背面供电、3D 集成）按理解层次介绍，并用已有验证方法讨论如何开始学习。

**自测**：用“概念—可能影响—需验证内容”回答，不写研究收益百分比。

### Q089 交付计划与 ECO 怎样连接技术风险

**要点**：将请求分成必要功能/性能问题与可延期优化，判断几何、连通、寄生、可靠性和接口影响，评估修改及回归时间。技术结论、责任人、版本与计划共同更新。Owner不能只阻止修改，也不能来一个做一个。

**自测**：关键ECO触及pad，列出需要共同决策的人与数据。

### Q090 更高能力标准怎样证明

**要点**：用独立规划、风险识别、疑难定位、检视与跨团队交付案例证明，而不是夸大年限或职责。角色与结果可被具体追问，技术知识与真实经历有对应证据。对尚未掌握的电路/工艺说明边界，并给学习/验证计划。

**自测**：选择三个真实项目案例，各说一个自己承担的关键判断。
