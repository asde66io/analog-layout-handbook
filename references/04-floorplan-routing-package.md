# 第 4 章 Floorplan、布线与封装约束

本章覆盖 floorplan 输入、信号流与隔离、差分/高阻/屏蔽、电源网络与封装约束。规划既看电路，也看验证、封装和交付接口。

### Q031 开始画 IP 前需要哪些输入

**要点**：电路版本与功能框图、敏感/噪声网、匹配关系、电流/电压、工艺/封装、面积/长宽比、pin/pad 顺序、供电和交付条件。分清已冻结与待定项，并列风险。paper floorplan 先验证主要矛盾，不能只按器件总面积排矩形。

**自测**：哪些输入缺失时可先做，哪些必须先澄清？

### Q032 按信号流排布与隔离冲突怎么办

**要点**：短线减少部分寄生，但靠近噪声源、热源或共享回流可能更差。比较关键节点的性能预算与实际耦合路径，建立候选布局并用必要提取/仿真判断。明确硬约束和可交换的面积/线长，不能用“信号流永远第一”作统一规则。

**自测**：一个敏感输入需要穿过数字区，列出两种可验证方案。

### Q033 TOP DOWN 如何变成可执行动作

**要点**：先规划模块尺寸、接口方向、跨域通道、关键层、供电和隔离，再对子块提出约束。一个典型例子是提前考虑 level shifter 穿线拥堵，而不是等拼接后才绕线。中期用关键路线试布确认预留，再随前端变化更新接口和风险。

**自测**：画一个通道示意，解释为何不能由每个子块自行占满边界。

### Q034 差分走线除等长还看什么

**要点**：层、宽度、via、分支与负载、屏蔽、相邻攻击网、回流及端点环境均要等效。等长并不保证两路 R/C 或延迟相等。关键结构先安排相同拓扑，再用提取比较互连；不为追求几何等长绕出更大不对称耦合。

**自测**：一条经过单孔、另一条经过孔阵列，等长是否足够？

### Q035 高阻节点为什么更怕耦合

**要点**：小电荷注入可能产生明显电压变化或建立尾部，风险与阻抗、总电容、攻击网幅度/边沿及采样时刻共同有关。先识别受害网和攻击网，再优化并行长度、层次、间距和屏蔽；最终比较毛刺、噪声及电路容限，不用绝对电容单独排序。

**自测**：时钟只在非采样窗口翻转，如何判断实际影响？

### Q036 屏蔽为何也可能让带宽变差

**要点**：屏蔽改变攻击网互耦路径，却可能增加对屏蔽网络的电容负载。屏蔽应接有效且适当的参考，检查连续性与回流，浮空或接噪声电源可能无益。比较屏蔽前后完整提取，确定隔离收益是否抵消负载损失。

**自测**：你会比较哪些指标来决定保留屏蔽？

### Q037 电源网络怎样兼顾 IR 与噪声

**要点**：检查源点、负载、支路和共享阻抗，区分静态与动态电流。敏感 bias/sense 与大电流回路合理分开，避免只按短线共用回流。单点、树状或网格没有绝对优劣；按 pad、封装、面积和负载做分析。改拓扑后重新检查 EM、IR 和性能。

**自测**：敏感模块地弹来自哪里，单纯增宽一段线能解决吗？

### Q038 Feedback 与 Kelvin 取样如何放

**要点**：force 路径承载电流，sense 路径用于感知目标节点，位置决定环路实际调节的电位。取样点应覆盖设计要补偿的线阻，保持模型/提取与实际连接一致。跨层次 pin/抽头错接可能让后仿看不到实际损失。

**自测**：画出“取样在电源端”和“取样在负载端”的差别。

### Q039 FC 与 Wirebond 的版图差异

**要点**：FC 要协调 bump/pad 位置、局部应力和电流接入；Wirebond 要协调 pad 顺序、引线/顶层通道及供电/泄放路径。封装变化即使底层复用，也要检查新顶层互连、回流、ESD 和模型边界。

**自测**：封装要求改 pad 时哪些团队应参与？

### Q040 IP 拼接后还需哪些模拟侧检视

**要点**：接口连通、相邻层/阱、隔离、数字攻击网、供电、天线、密度/fill 和边界保护等可能变化。按项目约定拿到相关集成数据与报告，核对 waive 范围和新增环境。切片宽度和 seal ring 责任是具体流程约定，不能把某个项目的数值当作统一检视规则。

**自测**：子块报告通过，哪类新增风险只能由顶层检查？
