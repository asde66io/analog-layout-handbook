# 第 6 章 PEX、后仿与误差归因

本章覆盖 PEX 输入核对、提取角、耦合保留、后仿定位与寄生优化验收。不要因后仿失败就直接归因版图，也不要因工具生成了文件就认为提取正确。

### Q051 PEX 输入必须核对什么

**要点**：布局/LVS 数据、提取 tech 与工艺、corner/温度、层映射、模式、单位、耦合/过滤、fill 和层次边界。模型与提取需一致，确认是否含衬底/电感等所需效应。用简单结构手算量级辅助判断，再交付网表及配置记录。

**自测**：一根线电阻异常大，先核对哪三项？

### Q052 工艺角与提取角为何不是同一件事

**要点**：器件过程角描述模型变化，互连提取角描述几何/材料等导致的寄生变化，组合与最坏场景按项目方法学定义。温度还影响器件与互连。不能把 SS 当作所有指标和全部寄生的统一最坏角，应依据电路指标与验证矩阵选择。

**自测**：为何最快器件角也可能是噪声或动态压降的危险条件？

### Q053 C only RC 与耦合保留如何选

**要点**：C-only 可帮助隔离负载电容效应，RC 纳入串联压降/建立问题，保留互耦能分析攻击网相关性。选择取决于关注指标和精度预算，简化模式不能自动替代最终签核。对比实验必须使用相同电路、激励、corner 和观察点。

**自测**：C-only 好、RC 差，下一步如何定位？

### Q054 如何区分模型本征寄生与互连寄生

**要点**：核对器件模型、抽取器件参数、寄生归属与排除设置，查是否遗漏或重复计入。用孤立器件、改变尺寸/走线与对照提取做最小实验，再找 CAD/模型团队确认。怀疑 PDK 或模型问题时，先用最小实验给出可复现证据，并与 CAD/模型团队确认；不能把怀疑直接当成结论。

**自测**：换器件尺寸后问题消失，是否足以证明工具有 bug？

### Q055 容值比例误差如何表达

**要点**：先确定目标比例与参考对象，用一致提取边界得到实际比例，再算相对偏差。例如某 SAR ADC 项目要求电容比例误差优于 0.1% 量级：这类指标要说明包含哪些寄生、参考对象是谁。ADC 的位数规格不能直接换算成实测 ENOB，也不能把比例误差等同整机线性度。

**自测**：同一组电容两次抽取设置不同，结果是否可直接比较？

### Q056 带宽下降怎样按因果链定位

**要点**：先统一前后仿输入与模型，再分别看工作点、关键极点/负载、串联 R、互耦和供电/回流。按网络或效应分组隔离，找主导项后比较缩短、换层、拓扑与屏蔽方案。与前端确认裕度，避免反复追求无关的小寄生。

**自测**：说明为什么先与前端确认前仿裕度能减少无效迭代。

### Q057 后仿不收敛的排查顺序

**要点**：先查连接/端口、模型 include、单位、浮空与工作点，再查初始化、关键寄生及仿真条件。缩小到子电路比较，必要时用受控的数值设置诊断；恢复合理精度并复验。单纯放宽容差让仿真跑完不能证明设计正确。

**自测**：哪个现象会让你优先怀疑网表端口顺序而非数值容差？

### Q058 加宽金属为何不总提升速度

**要点**：加宽通常降低电阻，却可能增加面积电容与邻近耦合；via、端点和驱动也可能主导。高阻节点、电源路径和时钟需要不同目标。先看主导时间常数和电路指标，比较宽线、短线、换层和拓扑，而不是一律加宽。

**自测**：高阻采样节点与功率电源线，优先优化分别是什么？

### Q059 顶层后仿比子块差如何定位

**要点**：检查负载、供电与激励是否一致，以及长互连、共享阻抗、邻网、衬底、fill 和封装环境。把顶层寄生按原因分组做对照，避免只盯子块已优化的局部。问题根源若在回流或隔离，可能需要调整 floorplan 而非改一个器件。

**自测**：子块用理想地、顶层含回流寄生，如何比较才公平？

### Q060 如何证明一次寄生优化有效

**要点**：固定模型、配置和版本，记录原方案与候选的几何/提取差异，对照最终电路指标及可靠性。报告性能改善、面积/复杂度代价和受影响的回归项。不要只报某个 C 减少多少，忽略另一路失配或供电变差。

**自测**：给优化结论列出最少需要保存的输入和输出。
