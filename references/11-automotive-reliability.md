# 第 11 章 车规可靠性专题

本章对比车规项目与普通项目的可靠性输入：寿命、任务剖面、温度 Grade、HTOL 与功能安全边界。参加车规项目、承担某个模块版图，与负责整芯片资格验证或功能安全分析是不同层次。

### A01 车规与普通项目应比较哪些输入

**要点**：这是工程检查建议；具体项目可能比另一类项目更严或更宽，不能只凭“普通/车规”名称排序。下表给出两类项目的重点核对维度。

| 维度 | 普通项目也必须确认 | 车规项目的重点核对 |
|---|---|---|
| 寿命 | 目标使用年限与实际开机时间 | mission profile 与累计通电时间，不能只用日历年数代替 |
| 温度 | 工作温度、功耗和局部自热 | 冷热范围、结温/金属温度、各温区停留时间 |
| 电流 | DC/AC、频率、占空比、peak | 正常与关键工作状态下的寿命限制及模型适用性 |
| 器件老化 | HCI/BTI 等适用模型与偏置 | 寿命末期关键性能与匹配是否满足目标 |
| EM/IR | 正确 tech、输入、路径与报告 | 使用车规项目认可的寿命/温度条件，复核 via 和局部热点 |
| 制造与变更 | DFM、PV、版本和回归 | 变更可追溯、资格验证影响、风险关闭证据 |
| 质量与安全 | 产品质量目标 | 可靠性与功能安全要求分别确认，不用一个指标代替另一套流程 |

### A02 EM的5年10年究竟是什么

公开研究讨论了5年、10年及更长应用寿命目标；它们不是全部foundry通用的菜单选项。某套tech可能通过寿命参数、不同限流表或预标定规则表达要求，是否支持某档位要看实际文档。

**参考表述**：我会先核对这是连续工作寿命、等效运行小时还是任务剖面下的寿命，连同温度、电流波形与失效判据一起确认。相同条件下更长寿命通常要求更低应力或更严格限制，但不能自己把5年限流表简单减半当作10年规则。

**教学例子**：若产品按非闰年365天连续工作，5年约43800小时，10年约87600小时；若每天运行4小时，10年运行约14600小时。真实产品的休眠、不同温区和工作负载应分别计入，不能只乘一个开机占比就完成所有失效机制的换算。

### A03 普通5年车规15年能当固定规则吗

不能。2018年ISPD厂商技术报告曾给消费类3–5年、车载娱乐10–15年、安全应用10–20年等市场示例，这说明不同用途的目标不同，并非当前统一标准，也不能直接当成某个具体项目的实际档位。

一份汽车数据转换IP的厂商说明采用15年生命周期例子，并强调温度分布与Power On Hours；这也不能代替具体项目的签核条件。

参考表述示例：某项目有车规应用背景，自己负责其中 ADC 模块的版图、线道与定制电容。普通和车规的区别，首先看寿命与任务剖面，再核对工艺 tech、温度、老化和验证条件。具体年限和 Grade 以项目报告为准，不把公开例子当成该项目数值。

### A04 年数怎样进入EM判断

Black类经验模型用于理解寿命与电流密度、温度的关联，但参数、分布和失效定义由工艺标定。除平均寿命外，项目可能要求特定失效概率/FIT目标；模型均值不能直接当全部器件的保证寿命。

设计动作是核对每层、via与接触的适用限制，识别局部电流分配和温升，比较路径/线宽/有效孔/供电拓扑，并在实际条件下重跑。工艺模型的系数、允许恢复效应或寿命换算未经确认，不从论文拿一组参数套用。

**自测**：延长目标寿命后为什么“加孔数量翻倍”不一定足够？回答应包含局部均流、温度、金属瓶颈和规则判据。

### A05 温度Grade与HTOL为什么不同

AEC-Q100 Rev J表1列环境工作温度：Grade0为−40至150°C，Grade1为−40至125°C，Grade2为−40至105°C，Grade3为−40至85°C。这不是所有EM计算使用的金属温度。

Rev J表2的HTOL包含各Grade对应的1000小时基准条件及说明。HTOL是加速工作寿命应力试验，不能简单说“做1000小时就等于EM验证10年”；需要适用失效机制、加速模型和实际条件支持换算。

工程中区分 Ta、Tj 与局部金属温度。若项目用更高的结温/局部温度做 EM，不能把环境 Grade 上限直接替代；具体温度分布与最终设置需回看项目报告。

### A06 AEC Q100与功能安全的边界

AEC-Q100是IC资格验证规范；标准并不由AEC认证委员会逐一签发证书。采用AEC方法的产品资格验证与ISO26262相关功能安全工作不同，不能互相替代。

版图侧需要准确落实相应约束、记录验证与变更影响，系统诊断、ASIL 目标、故障覆盖或资格验证的主导工作应按实际分工说明。没有掌握完整结果时，使用“参与车规背景项目的模块版图”而非“我完成了整芯片车规认证”。

参与车规项目前的核对清单：应用类别；EM寿命档位/等效小时；温度及局部自热处理；对应tech/deck版本；实际承担的验证；Grade与资格验证状态。不记得配置可以说需要核对，不虚构数字。
