# 第 10 章 专题工程细节

本章是 30 个专题工程细节单元，覆盖 FinFET 实操、匹配实操、寄生实操、脚本实操与签核实操。

### Q091 NFIN nf 与 m 的尺寸含义

**要点**：分别确认单指 fin 数、finger 数、整体复制数以及模型中 W 的含义。相同总驱动规模不代表相同源漏共享、栅电阻、结电容或环境。不要直接把某个 PDK 的 W = m × nf × Wfinger 约定套到另一套 PDK；FinFET 的有效宽度近似只用于理解结构，最终以 CDF、模型与抽取参数定义核对。

**练习**：电流镜需要 1:1.5 比例，先将其变成 2:3 个相同单位单元，再说明方向、dummy、连接和 PVT 回归。验收：能解释“总 fin 数一样”为何仍需比较寄生与 LVS 参数。

### Q092 PODE 与扩散边界环境

**要点**：认识 Poly on Diffusion Edge 是部分先进工艺中有源区边缘的栅或 dummy 结构约束。它与端部环境、图形规整性、隔离方式和面积开销相关。SDB、DDB 等扩散隔断方案可能改变邻近应力，匹配单元的左右环境要一致。不同工艺支持的结构不同，不能把“每端固定几根 dummy”“所有 FinFET 必须采用同一 PODE”背成普遍规则。

**练习**：两个同尺寸单元，一个靠扩散边界，一个位于阵列中部，列出要核对的 PCell、边界 dummy、隔断、LDE 参数和提取结果。验收：既能解释物理原因，也能说清由哪份规则确认合法性。

### Q093 MOL 中段互连的串联瓶颈

**要点**：区分 FEOL 器件、MOL 局部接触/互连、BEOL 金属。MD、VG、VD 等是手册使用的命名示例，并非所有 PDK 通用。把器件端子到高层金属画成一条完整连接链，逐段看接触电阻、包围、孔数量、局部电流密度和端子电压降。上层线很宽也可能被最底层接触或单孔限制。

**练习**：同一输出支路改宽 M2 后压降改善很小，画出接触—局部互连—via—M2 的电阻链，说明如何用提取排序定位。验收：不只回答“再加宽线”。

### Q094 Cut 线端与着色的联合约束

**要点**：cut 用于界定连续规则线条的端点或切断区域。线端延伸、via 包围、cut 间距和套刻余量会相互制约，局部修一条 DRC 可能制造另一条。匹配结构还要检查着色与图形环境，几何镜像不自动保证工艺等效；是否需同色或相应工艺相位由实际制造分解规则决定。

**练习**：一处 via enclosure 与 cut spacing 互相冲突，依次评估移 via、换层、重排线端和调整局部间距，并检查匹配路径。验收：能说明每种方案新增的寄生或面积代价。

### Q095 Pin 访问能力在摆放前检查

**要点**：pin 画出来不等于 router 或人工布线能合法接入。检查 pin 所在层与 track、候选 via、包围尺寸、周围 obstruction、端点 cut 及出口方向。对于密集匹配阵列，先试最拥挤的内部单元，防止摆完器件才发现出线必须破坏对称或额外占用通道。

**练习**：做一个 2×3 单元阵列，只画关键 pin 的合法引出路径，统计是否至少存在可用出口。验收：能把“布不通”追溯到 pin 层级、阻挡或 via 条件，而不是一概归因面积不足。

### Q096 从电路误差预算反推匹配要求

**要点**：先问指标是最大误差、均值偏移还是几倍标准差，再分系统性偏差、随机失配与寄生增量。用 PDK 定义的失配系数和电路灵敏度估面积，确认系数是否含两器件差分的 √2 因子；前仿 mismatch、global process 和后仿寄生的作用不能混为一谈。加面积主要改善某些随机项，不自动消除 WPE、LOD、热梯度等系统项。

**练习**：教学要求“3σ 电流误差不超过 1%”，先说明如何换成 σ≤约 0.333%，再列出所需模型系数和 gm/Id 信息。验收：不会把“1% 要求”直接当成 1σ，也不虚构工艺系数。

### Q097 用坐标检验共质心

**要点**：对等权单位单元分别算 x、y 坐标均值；不同权重按实际有效单元权重计算。共质心要求两组的加权质心重合。一阶线性梯度的贡献可以相消，但随机失配、非线性梯度和不同邻接环境不会因此自动消失。

**练习**：四个等间距位置为 x=0、1、2、3。ABAB 的 A 质心是 1、B 是 2，不是共质心；ABBA 的两组质心均为 1.5。二维阵列要同时检验 x 与 y。

### Q098 匹配器件与走线分别验收

**要点**：器件阵列按尺寸、方向、邻接、SA/SB 和阱边界检查；连线按金属层、长度、via、分支、屏蔽与相邻攻击网检查。镜像摆放本身不能替代 LDE 等效性确认。提取后对照两支路的 R、对地 C、互耦 C 与回流环境，最终用失调、增益误差、建立时间等电路指标判断。

**练习**：两个单元质心重合、pin 至汇流点距离却不同，提出先修连接拓扑还是先增大器件的理由。验收：能区分器件失配与互连不平衡，并用分组后仿验证。

### Q099 电阻端头和短条比例误差

**要点**：理想条体估算 R≈Rsh×L/W，实际还包含接触、端头电流扩展及弯折等贡献。对短电阻，两端附加项的相对占比更大；只按长度做 1:2，整体阻值未必严格 1:2。优先使用 PDK 模型支持的相同单位段和一致端头，串并联时核对端头是否重复计入，避免在模型之外再次加同一份寄生。

**练习**：教学例中 Rhead=10Ω、条体分别为 100Ω 与 200Ω，两端总计 20Ω 后比例变为 120:220。验收：说明为何这是解释原理的假设值，而不是可直接用于你的工艺的数值。

### Q100 电容底板与邻近环境的寄生

**要点**：分别确认有效电容与端子对衬底、下层金属、周围布线的寄生。底板接较低阻节点是常见思路，但开关电容的时序和误差目标可能提出不同要求，应由电路意图及模型确认。MIM/MOM 不宜凭名称断言哪一种寄生总更小；匹配单元的底部 fill、屏蔽与相邻信号也要一致。

**练习**：同一个阵列只改变底部金属环境，列出需比较的容值、底板寄生、失配与采样建立误差。验收：不会只验面积和 LVS 容值就认为动态性能相同。

### Q101 分布 RC 与 Elmore 估算

**要点**：真实长互连是分布 RC，不能只用总 R、总 C 判断每个端点延迟。对 RC 树，Elmore 时间常数为各节点电容乘“到该节点与到目标节点的公共路径电阻”再求和。它是响应的一阶矩估算，不等于普遍精确的 50% 翻转时间；遇到复杂耦合、电感、非线性驱动，应回到电路仿真。

**练习**：驱动端—R1—节点1—R2—节点2，节点电容为 C1、C2，末端估算为 R1(C1+C2)+R2C2。验收：能指出 R1 加宽与 R2 加宽影响不同，以及模拟路径不能随意插数字 buffer。

### Q102 保留耦合 接地与丢弃的差别

**要点**：保留互耦电容可以表示两个网络间的电压变化与串扰；折到地主要近似负载，丢弃则连总负载都可能改变。具体折算系数和过滤判据由工具配置决定。高阻、小电容、采样窗口敏感的节点要重点保留关键攻击网，不能因为某个绝对电容“小”就判定可忽略。

**练习**：同一敏感 block 分别用默认、收紧耦合阈值提取，其余条件不变，比较失调、建立时间、毛刺和噪声。验收：能用指标误差决定配置，而不是照搬手册中 1% 或某个 fF 的通用门限。

### Q103 DSPF 与 SPEF 的读取核对

**要点**：DSPF 常用于晶体管级后仿数据，核对子电路端口、寄生网络、实例连接和模型参数；SPEF 核对单位、名称映射、端口与连接、电容和电阻段。不能仅凭扩展名决定是否适配当前仿真器。检查层次分隔符、转义字符、全局电源名、是否重复包含器件，以及节点映射是否完整。

**练习**：选一个实际提取文件，按“单位—顶层—端口—一条关键网—实例模型”读一遍；有相应工具时运行官方网表检查器。验收：能指出哪一段数据用于何种验证，避免单位错千倍或子电路重定义。

### Q104 RC 网络缩减与误差验收

**要点**：缩减通过等效网络保留关注的动态行为，不能理解成随意删掉小电容。需确认关注频段、观察端口、负载、关键耦合及适用误差。低频等效相近不代表高频、启动或建立尾部相近。模型降阶误差与器件模型、提取角、仿真容差的变化应分别评估。

**练习**：以未缩减网表为参考，在同一 testbench 下比较工作点、AC、瞬态建立和关键杂散；记录节点数、运行时间和性能误差。验收：可以说明速度收益用了多少精度代价。

### Q105 Fill 与屏蔽之后重提取

**要点**：fill 影响附近电容及环境，接地与浮空 fill 的效果不同；屏蔽可能降低攻击网互耦，同时增加对屏蔽网络的负载。不要简单记成“加屏蔽就降低所有寄生”。检查密度窗口和敏感区约束，评估最终 fill、拼接与屏蔽版本，再从最终版图提取并回归。

**练习**：做原版、加屏蔽、加最终 fill 三个版本，对比密度通过情况与关键指标。验收：明确哪份 GDS 对应哪份 PEX 和后仿结果。

### Q106 SKILL 类型 真值与数据结构

**要点**：分清数值、string、symbol、list、array/table 和数据库对象；nil 为假，0 不能按 Python 的规则当假。层/purpose、坐标和属性名按 API 需要传正确类型。大型列表反复尾部 append 可能造成性能问题；按访问模式选择结构，避免百万对象中循环做线性查找。

**练习**：解释 0 与 nil、symbol 与 string、对象句柄与普通 list 的差异；将反复列表查找改为预建索引，并比较输出是否一致。验收：能说清正确性问题和性能问题分别出现在哪里。

### Q107 DBU 栅格与层次坐标变换

**要点**：确认每套 API 使用整数 DBU 还是微米浮点坐标，再区分数据库精度与制造栅格。整数坐标并不自动 on-grid。跨层次统计需累计实例旋转、镜像和位移；原点变换正确不代表 bBox 已正确，通常要变换角点后再求包围盒。

**练习**：教学 DBU=0.001µm，10µm 对应 10000 DBU；制造栅格若为 0.005µm，则坐标还需按 5 DBU 对齐。再用一个镜像子实例检查其全局位置。验收：能说明转换与 round/snap 次序。

### Q108 Cellview 打开 保存与关闭

**要点**：显式区分只读查询与修改模式，确认打开成功、权限、锁及返回对象，再操作、验收和按策略保存。save 与 close 的职责不同；发生错误后清理句柄和资源，不自动保存半完成设计。dbOpenCellViewByType、dbSave、dbClose 等名称来自手册示例，参数签名和具体行为需核对本地工具版本。

**练习**：设计“找不到库、只读库、对象失效、保存失败”四种失败路径，分别决定停止、跳过、回滚和记录内容。验收：输出明确失败名单，而不是只显示脚本执行结束。

### Q109 PCell 可重复求值与边界参数

**要点**：把几何结果建立在声明参数和明确工艺数据上，避免依赖 GUI 选择、当前窗口、时间或不受控的外部状态。验证合法参数范围、整数要求、栅格、pin/label、模型属性和各层规则。相同参数重复求值应产生一致几何；合法边界值、非法输入、跨版本都需覆盖。

**练习**：用最小、典型、最大三个合法参数组合生成同一类 PCell，分别检查几何、pin、DRC 和 LVS；非法参数应明确拒绝。验收：不会用“图形生成成功”替代电学与规则验收。

### Q110 可重复运行与异常清理

**要点**：同一输入运行两次时，脚本应更新自己生成的对象或明确拒绝重复，不能无意叠加 via、label、dummy。为生成对象记录归属和稳定标识；先做只报告的预览，再做小样本修改。跨工具未必支持真正的数据库事务，不应假定 undo 能覆盖所有文件输出，备份和恢复要单独设计。

**练习**：第一次生成、第二次重跑、中途人为报错、恢复后重跑，分别对比对象数、几何及连通性。验收：不会删除人工原有对象，失败也不会被记为成功。

### Q111 Tcl 引号替换与外部命令

**要点**：区分 Tcl 的花括号与双引号分组，理解变量、命令替换及反斜杠处理。含空格、括号或特殊字符的路径，优先用正确的参数列表构造命令，避免把数据直接拼成可执行脚本文本。生成 runset 后核对实际解析结果、退出码与工具日志；提交作业成功不等于验证通过。

**练习**：用带空格的测试路径调用一个只回显参数的程序，比较参数是否被拆开；再设置明确的失败退出码验证上游是否识别。验收：分别解释 shell、Tcl、EDA runset 哪一层在解释字符。

### Q112 脚本回归与性能分析

**要点**：黄金用例覆盖典型、边界、非法输入、深层次、旋转镜像、空对象和大数据量；同时看几何、端口、参数、DRC/LVS 和日志。性能分析拆开数据库读取、几何处理、文件输出与外部工具耗时，优先减少重复遍历和 GUI 刷新。PDK、API 或生成逻辑变化后重跑相应回归。

**练习**：同一脚本记录优化前后对象数、耗时、内存和输出差异；说明哪些结果必须完全相同，哪些只允许有明确容差。验收：不会把快了多少倍当作唯一成功标准。

### Q113 Soft Connection 的结构排查

**要点**：依据 deck 判断软连接的具体含义，检查阱/衬底、tap、contact、金属引出和网络命名，而非只看 LVS PASS。意图内的高阻连接与意外借阱连通要区分。不能用重命名电源或放宽规则掩盖偏置问题；豁免需有设计意图、风险验证和评审记录。

**练习**：body 只经阱连到另一处 tap，画出硬连接与软连接路径，说明为何逻辑等效不代表电气可靠。验收：给出修复后的连通性、偏置和必要可靠性回归。

### Q114 黑盒通过与内部签核的边界

**要点**：明确哪些内容在顶层仅检查边界端口，哪些内部内容必须由子块报告保证。核对黑盒/abstract 与实际 GDS、端口、模型版本和坐标是否一致；顶层连接、天线、密度、跨边界 ESD 路径或供电仍可能需要重新检查。黑盒节约运行时间，不应变成“免检证明”。

**练习**：列一个 IP 交付清单，标明每项由 IP 方还是集成方验证、使用哪一版本。验收：能解释顶层 LVS PASS 覆盖了什么、没有覆盖什么。

### Q115 签核结果与版图快照一致

**要点**：签核包绑定最终 GDS/OASIS、top cell、layer map、工具/PDK/deck、runset、提取角、日志、豁免和关键文件校验值。记录最终 fill 和 ECO，避免“报告是 clean，版图却又改过”。多工具结果不一致时先用最小测试结构统一输入与设置，确认差异来自规则、模型、单位还是实现。

**练习**：最终签核后有人改一个 pin，说明哪些旧结果已不再直接对应交付快照，以及如何按影响范围决定回归。验收：可以从任一报告追溯到准确输入版本。

### Q116 平均 RMS 峰值与 via 瓶颈

**要点**：分别理解有向平均电流、RMS 与峰值对应的不同风险，最终按工艺 AC/DC EM、恢复系数、peak 和自热规则判定，不能把“所有 EM 只看平均”背成定律。分支、转角、宽窄过渡、slot、接触和 via 都可能成为热点；阵列通孔不应简单假设每孔均流。

**练习**：单向矩形脉冲峰值 10mA、占空比 25%，Iavg=2.5mA、Irms=5mA、Ipeak=10mA。再解释双向脉冲平均为零也不能免掉全部可靠性检查。验收：按每段路径而不是整网总电流检查。

### Q117 温度 自热与寿命的联合评估

**要点**：区分环境温度、器件温度和金属局部温度。自热、邻近热源与温度相关电阻可能进一步影响 IR 和 EM。Black 方程可用于理解寿命随电流密度与温度变化的趋势；其参数与有效失效机制属于工艺数据，不应用手册中的通用数字宣称实际寿命。

**练习**：一个支路在典型温度合格，热源开启后局部电阻与温度上升，列出波形、局部温度、IR、各层限值和 via 回归步骤。验收：修复某处热点后会重新检查余下路径，而不是只看原违例数量。

### Q118 PPAC 的成本维度

**要点**：在功耗、性能、面积之外，区分晶圆加工、掩膜、良率、测试/封装以及开发投入。教学粗模型为良品裸片成本≈晶圆成本÷（可切割裸片数×良率），这不是完整报价模型。面积缩小、额外工序和良率变化可能相互抵消；可选器件带来的额外工艺成本需由工艺方案确认，不能仅按器件名推断。

**练习**：在相同晶圆成本假设下，方案 A 有 1000 个裸片、良率 90%；B 有 1200 个、良率 70%。比较 900 与 840 个良品，说明更小面积为何未必更低成本。验收：说出模型省略了哪些成本。

### Q119 面积口径与候选方案的同条件比较

**要点**：分别报有效器件面积、含 dummy/隔离/内部布线的 block bbox、顶层通道和接口占用。先明确性能硬约束和比较条件，再比较两到三个方案的功耗、噪声/失调/建立时间、面积、寄生和可靠性。评价“更好”要看硬约束与代价，不能只报器件少了多少或某一指标提升。

**练习**：以一个 SAR ADC 电容阵列的教学结构做候选表：相同匹配器件，不同通道宽度或金属层。写下需要从最终 PEX/后仿得到的数据，不填未经证实的数字。验收：能说明方案选择怎样保护电路指标，并报告真实 block 面积。

### Q120 BPR BSPDN 与测试结构反馈

**要点**：BPR 是埋入式供电轨，BSPDN 是背面供电网络，两者并非同义词；存在组合方案，也存在不同连接实现。了解其可能释放正面布线资源、改善供电，以及增加工艺集成与对准挑战，不将逻辑工艺研究收益直接套到现有模拟 IP。

**练习**：工艺团队给出两种局部接触规则，设计接触链、Kelvin 电阻、密度/边界变化结构或简单单元，提出要测哪一指标才能判断规则收益。验收：区分“掌握概念、能提验证方案”和“亲自实施过背面供电”。
