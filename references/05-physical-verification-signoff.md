# 第 5 章 物理验证、器件识别与签核

本章覆盖 DRC/LVS/ERC/PERC 的分工、器件识别层、自定制 rule 验证与签核证据链。核心是“检查配置正确”和“结果有证据”，不是只追求报错数为零。

### Q041 DRC LVS ERC PERC 分别回答什么

**要点**：DRC 检查适用几何/制造规则；LVS 检查提取与参考网表的一致性；ERC 关注电气连接/偏置等规则；PERC 按配置做拓扑或布局相关可靠性检查。各自范围依 deck 而定，不能相互替代。全部 PASS 仍需确认覆盖场景和数据版本。

**自测**：LVS 通过能否证明负压 pad 的所有风险已覆盖？

### Q042 如何先排除验证配置问题

**要点**：核对 top cell、层映射、输入数据库、工艺/deck、开关、封装/电压选项、黑盒和 include，再看日志是否真正执行了所需检查。大量同类错误可能是映射或环境问题；先还原一个小结构，再修改设计，避免在错误配置下返工。

**自测**：运行很快且零违例，需要确认哪些项目？

### Q043 LVS 参数不匹配如何定位

**要点**：区分器件类型、数量、端口和参数。定位实际抽取对象，再对比模型、W/L、fin、nf/m、识别层和合并规则。原理图显示总尺寸与提取参数可能有不同定义，先统一口径；不要直接放宽容差让报告通过。

**自测**：总宽一样、nf 不同，哪些信息决定等效与否？

### Q044 短路与断路有哪些高效定位方法

**要点**：按报告中的网络与层次缩小范围，高亮端口、金属、contact/via 和边界；对短路找最小共享连接，对断路从两端走查路径。核对 label/net 命名和层映射，避免把几何邻近当成电气连接。必要时用子块隔离或差异检查定位新增问题。

**自测**：与旧 clean 版本对照时，先看哪些改变？

### Q045 Soft Connection 如何关闭

**要点**：按 deck 确认哪些高阻阱/衬底连接触发标记，检查 tap、接触和金属引出及 body 偏置。逻辑连通不代表有效低阻连接。修复后复验相关连接和可靠性；仅在意图明确、证据充分且评审认可的情况下按范围豁免。

**自测**：为什么增加一个 label 不能解决真实 body 高阻偏置？

### Q046 Label Pin 与全局网名怎样影响验证

**要点**：名称、层/purpose、位置、层次和全局网处理选项影响提取。错误电源同名、pin 掉在错误层或端口顺序不一致可引入假短接/不匹配。批量脚本必须校验端口名和实际几何连接，不能只看文字。

**自测**：一条金属没有物理接到 tap，打上 VSS 字样是否足够？

### Q047 识别层与制造层怎样区分

**要点**：有些 marker 用于器件抽取、规则分类或校验，有些真实层直接控制制造。它们可能同样出现在版图数据库里，但作用不同。自定制电容识别规则需明确构成条件、端口和参数，验证正反例；不能随意删“看似不制造”的层。

**自测**：自定制 rule 如何避免把普通走线识别成电容？

### Q048 自定制 rule 怎样验证可信度

**要点**：定义目标与边界，准备应报错、不应报错、极限/组合和跨层次用例，检查层映射、几何操作、端口与单位。与已知结构或人工判断对照，维护版本和回归。清零一个大项目不等于 rule 准确，漏检和误检都要评估。

**自测**：讲一条你确实写过或维护过的规则，并区分个人完成部分。

### Q049 黑盒与层次验证的前提

**要点**：黑盒限制内部检查，只比较约定的边界；内部正确性需由对应版本子块报告保证。检查 abstract、GDS、网表和端口的一致性，以及拼接后的天线、密度、供电等。hcell/层次加速与黑盒免抽取并非同一个概念。

**自测**：LVS box 开关错误可能掩盖什么问题？

### Q050 Waiver 与 signoff 的证据链

**要点**：每项豁免应说明规则、对象/坐标、输入版本、原因、风险验证及审批；新增 ECO 或环境变化可能使旧理由失效。signoff 对应冻结数据库与完整检查范围。最终 GDS、runset、日志和报告可追溯，不能用旧报告给新数据背书。

**自测**：交付前修改一个 pad，哪些结论必须重新评估？
